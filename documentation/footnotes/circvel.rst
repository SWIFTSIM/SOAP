**The maximum circular velocity and the radius where it is reached** are
computed using

.. math::

   v_{\rm{}max} = \sqrt{\frac{G M(\leq{}r)}{r}},

where the cumulative mass :math:`M(\leq{}r)` includes all particles within the radius :math:`r`, and includes the
contribution of the particle(s) at :math:`r=0`. The radius is computed relative to the halo centre.
The softened :math:`v_{\rm{}max}` value is calculated using the same method, except that the particle
radius has a floor equal to the softening length. An alternative way to calculate :math:`v_{\rm{}max}`
is to estimate it from the halo concentration by assuming an NFW profile.
Note that the softened vmax is *not* the :math:`v_{\rm{}max}` computed using a softened potential.
